🎲 Dicee Game – Refresh to Roll! 🎲
Welcome to Dicee Game, a simple yet exciting dice rolling web app built with HTML, CSS, and JavaScript! 🎲✨

🎯 How It Works:
Just refresh the page and let the dice roll! 🔄
Two players get a random dice roll every time the page reloads. 🎲🎲
The player with the higher number wins! 🏆
If both players roll the same number, it's a draw! 🤝
💡 Tech Stack:
✔️ HTML – Structuring the game layout.
✔️ CSS – Styling with a fun and modern UI.
✔️ JavaScript – Handling the logic and random dice rolls.
